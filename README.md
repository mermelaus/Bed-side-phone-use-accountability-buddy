# Bed-side-phone-use-accountability-buddy
arduino code for an ultrasonic sensor based bedside phone detecting device to annoy a user with a buzzer when theyre supposed to be sleeping but theyre using their phone. Connects to an LCD screen, an ultrasonic sensor, and a buzzer. A button is taken as input to detect the change between night and day. during the day, a message is displayed, as well as a day counter (long distance relationship stuff), button is pressed-> night mode is engaged, during the night, program counts time until the button is pressed again, and also checks for an item close to the ultrasonic, if it doesnt find it is buzzes, this process does not occur during daylight mode.
